# Requerimientos - SIGR

## Requerimientos Funcionales
- RF01: Autenticación y autorización por roles (cliente, mesero, administrador).
- RF02: Gestión CRUD de menú (platos y categorías).
- RF03: Registro y seguimiento de pedidos en tiempo real.
- RF04: Gestión de reservas por fecha y hora.
- RF05: Cierre de caja y generación de reportes de ventas diarios.

## Requerimientos No Funcionales
- RNF01: Aplicación web responsiva.
- RNF02: Lenguaje Java, arquitectura hexagonal.
- RNF03: Disponibilidad mínima del 99%.
- RNF04: Seguridad mediante JWT y cifrado de contraseñas.
