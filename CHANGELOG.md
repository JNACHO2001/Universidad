# Registro de Cambios (CHANGELOG)

Todos los cambios importantes de este proyecto se documentarán en este archivo.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/)
y este proyecto se adhiere a [Versionado Semántico](https://semver.org/lang/es/).

## [1.0.0] - 2026-05-16

### Añadido (Línea Base Oficial)
- Estructura inicial del proyecto bajo arquitectura hexagonal.
- Módulo de autenticación de usuarios (clientes, meseros, administrador).
- Módulo de menú digital con CRUD de platos y categorías.
- Módulo de registro y seguimiento de pedidos en tiempo real.
- Módulo de reservas por fecha y hora.
- Módulo de cierre de caja y reportes de ventas diarios.
- Documentación base: arquitectura, requerimientos y línea base.
- Configuración inicial de Git y plantillas de entorno.
