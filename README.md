# SIGR - Sistema Integral de Gestión de Restaurante

**Línea Base Oficial:** v1.0.0
**Lenguaje:** Java
**Tipo:** Aplicación Web
**Arquitectura:** Hexagonal (Puertos y Adaptadores)
**Control de versiones:** Git (rama principal: `main`, tag: `v1.0.0`)

## Descripción
Aplicación web para gestionar pedidos, reservas, administración de menús,
control de caja y generación de reportes en un restaurante.

## Módulos incluidos en la línea base
- Autenticación de usuarios (clientes, meseros, administrador).
- Menú digital con CRUD de platos y categorías.
- Registro y seguimiento de pedidos en tiempo real.
- Reservas por fecha y hora.
- Cierre de caja y reportes de ventas diarios.
